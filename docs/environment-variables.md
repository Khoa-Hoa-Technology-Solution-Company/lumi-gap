# Environment key inventory

The local template is root `.env.example`. Backend tuning has defaults in `EnvSchema`; Docker overrides internal hostnames. Production retains its separate credential contract.

Users can also save multiple personal API connections in Settings → AI Connections. See [Personal AI connections](PERSONAL_AI_CONNECTIONS.md) for supported protocols and setup.
